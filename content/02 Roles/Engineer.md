# Engineer
> [!summary] 🟢 Simple
> The **technical lead on site**. Writes requirements (materials, specs), reports progress and issues, creates tasks, marks milestones done, and asks for budget changes when needed.

## Features (scope)
Dashboard (assigned projects, pending requirements, critical issues, calendar) · Projects · Approvals (budget change requests) · Progress Updating (engineering reports with measurements/observations) · Requirement Drafting (template packs) · Issue Reporting (with suggested resolutions) · Tasks · Requests (raise RFI/RFA — PM countersigns)

## 🔵 Technical notes
- **Requirement drafting** = rule-based *template packs*, not an LLM call. → [[Decision Support Overview]]
- **Issue reporting** surfaces similar resolved issues ("issue precedent") → [[Signals]]
- Can **mark milestones completed** (decision Oct 2026).
- Starts **Budget Change Request** (first stage) and **Project Closeout** workflow (Final Inspection sign-off).
- An Engineer's RFI draft needs the PM to "send" it (countersign).
